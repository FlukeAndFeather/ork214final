# Data of Stream Nutrient Concentrations before and after Hurricane Hugo

# Purpose
This repository houses all data necessary to reproduce Figure 3 of Schaefer etl al. (2000), which shows changes in the concentration of five nutrients in streams in Bisley, Puerto Rico before and after Hurricane Hugo.

# Contents
This repository includes indvidual .csv files from the four long term research sites in the study streams.

## QuebradaCuenca1-Bisley.csv
This csv file includes data from the Quebrada Cuenca 1 Bisley long term research site (Q1 or BQ1), spanning from 1986 to 2020.

## QuebradaCuenca2-Bisley.csv
This csv file includes data from the Quebrada Cuenca 2 Bisley long term research site (Q2 or BQ2), spanning from 1986 to 2020.

## QuebradaCuenca3-Bisley.csv
This csv file includes data from the Quebrada Cuenca 3 Bisley long term research site (Q3 or BQ3), spanning from 1986 to 2020.

## RioMameyesPuenteRoto.csv
This csv file includes data from the Rio Mameyes Puente Roto long term research site (MPR or PRM), spanning from 1986 to 2020.

# Key Variables

Variables/columns key to reproducing the figure include:

### Sample_ID
Specifies which site data was collected from.

### Sample_Date
Identifies the date of data collection (YYYY-MM-DD).

### NO3-N
Concentration of nitrate-N in the stream in ug/L.

### K
Concentration of potassium in the stream in mg/L

### Mg
Concentration of magnesium in the stream in mg/L

### Ca 
Concentration of calcium in the stream in mg/L

### NH4-N
Concentration of ammonia in the stream in ug/L

# Data Access:
The data package used in this analysis is available through the Environmental Data Initiative and can be found at the [McDowel and International Institute of Tropical Forestry (IJTF) 2024](https://doi.org/10.6073/PASTA/F31349BEBDC304F758718F4798D25458). 

Data in this repository includes the Quebrada one-Bisly (Q1) Chemistry Data, Quebrada two-Bisley (Q2) Chemistry Data, Quebrada three-Bisley (Q3) Chemistry Data, and Puente Roto Mameyes (MPR) Chemistry Data.
